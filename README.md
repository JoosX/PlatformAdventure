# Platform Adventure

Un juego de plataformas en 2D con estética retro pixel art monocromática (1-bit), desarrollado en Unity.

---

## 🎮 Acerca del Proyecto

**Platform Adventure** combina mecánicas clásicas de plataformas con una interfaz retro cuidada al detalle. El proyecto incluye un menú principal interactivo, transiciones entre escenas y una identidad visual inspirada en los juegos arcade y consolas clásicas.

---

## ✨ Características

* **Estética 1-Bit:** Arte en blanco y negro con sprites pixel art y tipografía retro.
* **Menú Principal Interactivo:**
  * Navegación dinámica con indicadores laterales (`◄ ►`) reactivos al cursor (*hover*).
  * Control de transiciones de escenas (`SceneManager`).
  * Estructura modular mediante `Vertical Layout Group` y componentes UI desacoplados.
* **Arquitectura de UI limpia:** Scripts independientes para el manejo de escenas (`MenuPrincipalManager`) y efectos visuales de botones (`BotonRetroHover`).

---

## 🛠️ Tecnologías Utilizadas

* **Motor:** Unity (Unity 6 / 2023+)
* **Lenguaje:** C#
* **UI:** Unity UI (uGUI) & TextMeshPro (TMP)
